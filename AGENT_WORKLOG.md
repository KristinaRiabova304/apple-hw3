## Final review

- **Agent/tool disclosure:** Claude Code (Claude Opus 5.5) generated the
  implementation, tests, `PLAN.md` draft, CI workflow, shared scheme, and this
  worklog draft. No other AI tools were used.
- **Accepted and rejected/revised recommendations:**
  - Accepted: MVC with one `StudentStore` created in `SceneDelegate` and
    injected into every controller; one list controller reused for the subject
    filter; detail screen stores only the student ID.
  - Accepted: fixing the starter's missing `configuration.delegateClass =
    SceneDelegate.self`, without which no screen would appear.
  - **Revised:** the agent's first UI tests tapped elements immediately and
    used `swipeLeft()` for deletion. They failed in run 2, so they were changed
    to wait for each element (`waitForExistence`) before tapping and to use an
    explicit press-and-drag gesture for swipe-to-delete.
  - **Revised:** relying on Xcode's auto-generated scheme (parallel simulator
    clones) was replaced by a shared scheme with `parallelizable = "NO"`, after
    the clones overloaded the machine.
  - **Revised:** the first detail-screen layout set stack alignment twice and
    split the avatar constraints; it was simplified before testing.
